# GuardianTrack

An IoT-powered Vehicle Tracking and Theft Prevention System featuring real-time GPS tracking, geofencing, threat detection, analytics dashboard, PDF/CSV reporting, and support for both simulation and ESP32 hardware modes.

## Features

* Real-Time Vehicle Tracking
* Geofence Monitoring
* Threat Detection
* Analytics Dashboard
* PDF Report Export
* CSV Report Export
* ESP32 Support
* Python Simulation Support

## Tech Stack

* Python
* Flask
* JavaScript
* Leaflet.js
* ESP32
* GPS Module

Project deployment in progress.
